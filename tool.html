怎么用

  1. 装好模拟器：推荐 MuMu 12，装好后在里面安装 TapTap + Arcaea 国服，登录并打完一次歌（只需一次）。
  2. 双击 exe：托盘会出现一个小图标，浏览器自动打开工具页面。
  3. 点「一键同步并提取」：等 1~2 分钟，看到账号、成绩数、B30 就成功了。
  4. 复制 a_t：粘到查分页的输入框，之后随时打开网页就能看成绩、导出长图。
注意：exe 请放在可写目录（比如桌面、D 盘），不要放 C:\Program Files，否则会报 Could not create temporary directory!。

常见问题

每次打完歌都要重新提取吗？
a_t 不用重新提取，长期有效。但完整的 B30 数据来自本地成绩库，打完歌想看到更新，需要再点一次「一键同步并提取」。
能不能查别人的成绩？
不能。国服接口只开放了 /webapi/user/me，没有任何读取他人成绩的端点。这不是工具的限制，是服务端没开。
支持哪些模拟器？
一键自动启动目前只支持 MuMu 12。雷电 / 夜神 / BlueStacks / 逍遥 需要你先手动打开模拟器，再点下面的「只提取」——功能完全一样，只是少了「帮你开机」这一步。
会不会封号？
工具只做两件事：用 adb 读模拟器里的本地文件、调官方网页版的公开接口。不修改游戏数据、不模拟对局。但毕竟不是官方工具，自己判断风险。
为什么需要管理员权限？
要执行 adb root 才能读游戏的私有数据目录。普通权限下 Android 会直接拒绝访问。
数据会传到哪里？
不会。所有读取和计算都在这台电脑上完成，成绩数据只写进你本地的 CSV，不会上传到任何服务器。
